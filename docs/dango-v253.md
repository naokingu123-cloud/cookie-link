# v253 — 月見団子の盤面・色付きの串・初期FREEの最低1個保証

版: `20261119-v253-dango-tsukimi-lines`。

v252から、初期FREEを1〜3個へ変更し、団子の状態色と盤面の配置を更新する。配当表は左上へ移し、成立しない配当セルを取り除く。盤面は右側へ寄せ、月見団子の台座に乗せて表示する。

**検証状況：実装中。ブラウザー検証、GitHubのmain保存、Pagesの公開確認は未完了。** 実行ID・対象コミット・検証結果は、実際の検証後に記録する。

## 初期FREEと配当率

新規ゲームでは初期FREEを最低1個、最大3個とする。前半5球で初期FREEの番号にHITした数に、基本1個を加えたものが配置できるFREE数となり、上限は4個。ライン成立による配置数の追加は行わない。

初期FREEの番号にHITしてもオッズは上がらない。配置FREEの番号が後半3球でHITした場合だけ、ODDSが1段階上がる。同じマスでの二重加算、FREEを置いた時点での加算、過去のHITへの遡及は行わない。

初期FREEがない盤面を廃止してもP/O50〜150%を設定できるように、初期FREEの位置・型の出現率と配当を再計算する。設定値の基準は、後半の番号を知らずに最適な手動配置を選ぶ場合の理論期待値。おまかせ配置は、現在のライン完成や長いリーチを簡易に優先する既存の方法を引き継ぎ、最適配当の探索へ変更しない。

配当は3個ライン1本を0.2→0.1倍、3個ライン2本を1→0.5倍、4個ライン1本を1→0.4倍へ調整する。ほかの10項目は維持する。厳密計算は [`dango-v253-calibration.json`](dango-v253-calibration.json)、再現ソースは `scripts/dango-v253-calibrate.cpp` に保存する。一様・非復元の8/25抽選を前提とし、整数メダルの丸め、共通Sugar／JPC、現実の物理抽選の偏りとは区別する。

前半5球の集合53130通りと後半3球1140通り、計60568200通りを扱う厳密計算により、新しい低配当型と他の型の混合で50〜150%を連続して設定できる。最高2000倍の配当は維持し、初期FREE3個型を全設定で0.5%残す。初期FREE1個の低配当型は最下段の左から2番目、またはその鏡像の位置を半々で使う。ほかの型は左右対称の配置を引き継ぐ。

| 設定・最適手動の理論P/O | おまかせの理論P/O |
|---:|---:|
| 50% | 41.507803% |
| 75% | 57.463358% |
| 100% | 72.098549% |
| 125% | 83.633554% |
| 150% | 94.158474% |

この差は、おまかせが配当最大化ではなく簡易なライン完成を優先するために生じる。設定値は「どの配置方法でも必ずその配当率になる」という意味ではない。

v251の途中チェックポイントを復元するときは、当時の配当とFREE条件を維持する。新しい最低1個の条件や配当表を、進行中の旧ゲームへ遡って適用しない。

## 団子の状態色

| 状態 | 表示 |
|---|---|
| 通常 | 白い団子 |
| 初期FREE | 三色団子の黄緑色。FREEの文字を大きく、明瞭に表示 |
| HITしたマス | 三色団子のピンク色 |
| 配置したFREE | 月見団子の黄色 |
| 配置FREEへの後半HITでODDS UP | 虹色の団子 |

番号は全状態で残す。見た目の色が変わっても、初期FREE・配置FREE・HITのゲーム上の区別は保持する。虹色は配置FREEへの後半HITを示し、初期FREEにHITしただけで虹色にはしない。

団子・台座は生成した画像を使い、既存ゲームの立体感、光沢、菓子の質感に合わせる。白い団子・竹串・背景にはv252の素材を引き継ぐ。新素材は `assets/dango-art-v253/` に保存する。

## 配当表と盤面の配置

配当表は左上に置き、有効な配当セルだけを表示する。行は **3個ライン・4個ライン・5個ライン・7個ライン・9個ライン**、列は成立本数。従来の「該当なし」のダッシュや空のセル枠を取り除き、各行の有効段数に沿った形にする。

| 行 | 有効な成立本数の段 | 色 |
|---|---|---|
| 3個ライン | 1本0.1倍・2本0.5倍・3本5倍・4本以上100倍 | 青 |
| 4個ライン | 1本0.4倍・2本3倍・3本50倍・4本以上500倍 | 緑 |
| 5個ライン | 1本3倍・2本100倍・3本以上2000倍 | 黄 |
| 7個ライン | 1本25倍 | 赤 |
| 9個ライン | 1本100倍 | 紫 |

配当欄の背景は、それぞれの色の明度を落とした黒に近い色にする。数字は他ゲームと同じ金色の `ArcadePayout` フォント、右寄せ、コンマなし。ODDS表示は配当表の近くに添える。表示金額には今回のBETと現在のODDSを反映し、長さ別に該当する1段ずつを合計してWINとする。

従来の盤面上部の段階・球数の文字を撤去し、配置できるFREEの残数は団子の右側へ移す。配当表の下を含む空間を盤面に使い、団子は接した状態を保って拡大する。25個の団子の下には月見団子の台座を表示する。

## 串・リーチ・もっちりした動き

完成した串は、長さに応じて青・緑・黄・赤・紫に色分けする。竹串の素材を残しつつ、団子と重なる部分でもラインが読める明るい線を重ね、光が串に沿って移動する演出を付ける。番号の可読性も維持する。

リーチの団子には、シックスドロップを参考にした輪郭の発光と光の移動を加える。通常・高額・超高額・最高役の判定は既存の各ゲーム自身のBETによる分類を引き継ぐ。串の長さの色と、リーチの重要度の色は別の情報として扱う。

静止中も団子がわずかに伸縮し、柔らかいもちの感触を表す。クリック領域は安定した位置に置き、見た目の動きで操作対象がずれないようにする。一時停止・非表示・動きを減らす設定を考慮する。

## FREE操作と共有抽選機

- 配置した黄色いFREEを再選択すると解除し、残数を1個戻す。
- 残り0個になっても、配置済みの団子を取り消して置き直せる。
- 確定ボタンと独立した戻すボタンは設けない。
- おまかせは未配置分だけを補う。
- 15秒の期限で未配置分を補完して確定し、6球目を渡す前に保存のACKを待つ。
- 保存済みの手動配置は保持し、遅れて届く古い保存で巻き戻さない。

共有抽選機の前半5球・配置時間・後半3球、物理発射の制限、期限の保存、精算の重複防止は維持する。ローカルの代替8球抽選は有効にしない。

全10ゲームの小タブのリーチはv252のまま、4個を2秒静止してから650 msで左へ送り、次の4個を右から表示する。空欄・高額/超高額ポップアップ・各ゲーム自身のBETによる判定も維持する。
