# Chocolate Canyon — directional drills v5 (2026-10-29)

## 抽選・番号
このゲームだけ1球ずつ（8回）。他の2ゲームは3,2,1,1,1を維持。上7本、左3本、右3本の計13本。左右は上から3・7・11段目を横方向に掘る。初期Lv.1、現在Lv.の地層数を連続掘削後、LvUP（最大5）。同じ塊は1地層。

方向別全掘削は上・左・右の3番号。上は7本、左・右はそれぞれ3本を現在Lv.で発射し、各発射ドリルは掘削後にLvUP。全LvUP専用番号・未HIT時の強化は廃止。

表示は13+3=16番号。HITした番号枠だけを処理済みでなく他枠と重複しない番号へ交換。掘削演出中に入った後続球は交換候補から除外しない。後続球と交換先が一致すれば、続けて同じドリルを掘削する。未HITでは盤面・レベル・番号に変化なし。

## 表示
共通ルーレット・タブ・ゲーム枠のサイズを変更せず、その下で7列12段の盤面を調整。横からのドリルも同一機体が連続移動。画像の中央の彫刻のみを残すことで連結辺の内側の縁取りを抑え、ビターは黒寄りの色に。空洞はチョコと異なる青緑の暗い背景。

盤面下にシュガーまでの距離。距離が架空にならないよう地下18m先に出現予定を持ち、実際のシュガーマスとして生成する（塊を分断しない生成位置、次は18m先）。生成済みなら最も浅いシュガーの実際の段までの距離を表示。取得条件は従来どおり露出で、深度だけで付与しない。

トロッコの積載鉱石の下にデジタル秤。BET依存の合計WINを0.9秒で連続加算表示。途中の増加は表示中の数値から再開し、ポーズ時は停止、リセット時は初期化。会計値そのものは演出で変更しない。

## 検証
80ゲーム、1000盤面、5画面サイズ。方向別攻撃・水平連続飛行・8球後の16番号重複なし・Lv上限・未HIT無変化・後続球による同一ドリル連続HIT・旧保存移行・リセットを確認。ブラウザーでは3ゲーム共通の上部座標一致、抽選配送8回対5回、秤の単調増加、1024オートタイル描画ケース、音声を確認。物理iPhone実機検証ではない。
