# チョコレートキャニオン

2ゲーム目。7列×12段、ミルク・いちご・ホワイト・抹茶の4色。同色の上下左右隣接が一つのケーキとなり、番号HITで連結全体を消去する。初期盤面の1〜25は各1個、同じ連結ケーキ内には複数番号を許す。新しい下層を追加した場合、その新規マスだけに欠けた未抽選番号を補充する。継続ゲームの開始前には番号を振り直す。

重力は連結単位の剛体落下。各1段の移動後に連結を再判定し、落下途中に同色へ接触した時点で合体する。一部が支えられたケーキ全体は停止する。移動依存関係を解いて同時落下させ、重なり・すり抜けを防ぐ。

銀・金の配当チョコはケーキ内に埋まる。ケーキを消しても配当チョコ自体は残り、同じ列の上に遮るケーキがなくなった瞬間に回収する。露出の判定は消去直後と各落下ステップの間に行う。銀1.1倍、金10.0倍。深さ・単純消去・合体自体には配当を付けない。

空いた最上段を1段につき1mとして取り除き、下層のケーキを追加する。画面横に10mごとの看板を表示する。8球終了時に配当があれば深さと地形を継続保存し、配当なしなら次ゲームの準備時に0mへ戻る。0 BETでは進行しない。途中リセットは開始前のチェックポイントに戻る。旧ショコラディグとは保存キーを分離し、旧データを誤変換しない。

シュガーは従来の10m到達ルールを維持し、1ゲームにつき最大1個。継続後の次の到達目標は次の10m刻みとなる。通常配当率はシュガー/JPCの価値を含めない。

固定生成パラメータ：隣接色を選ぶ確率35%、銀3.5%、金0.75%（新規地層の上2段は配当チョコなし）。プレイヤーの損益や抽選結果に応じて変更しない。

検証：同色連結、多番号同時HIT、落下途中の合体と停止、埋没配当の保持、露出時のみの配当、二重回収防止、盤面安定性、番号/ID一意性、80ゲームの実エンジン進行、継続と失敗時リセット、0 BET、保存復元、チェックポイント。ブラウザーでは320/390/430/1280幅と3ゲーム同時進行を検証する。

統計は継続した地形を次ゲームへ渡す連続プレイのモンテカルロ。1〜25から重複なし8球、処理単位3・2・1・1・1。乱数シード281028221と281028222、各20,000ゲーム。再現：`node .github/tests/canyon_payout_sample.cjs 20000 SEED`。

合計40,000ゲームの通常配当率は **88.792%**、500ゲーム単位のバッチ平均による近似95%区間 **85.76%〜91.83%**。継続によるゲーム間の依存を考慮するため、単純な1ゲームごとの独立性は仮定しない。配当獲得・継続率は **23.68%**。詳細は `chocolate-canyon-rtp-20261028.json`。
