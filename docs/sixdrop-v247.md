# シックスドロップ v247 — 1球処理・同色全消去・継続プログレッシブ

公開版識別子: `20261117-v247-sixdrop-single-progressive`
ゲーム名は「シックスドロップ」のまま。既存の生成ボトル画像を保持する。

## 実装ルール
- サーバーの8球は維持し、シックスドロップは1球ずつ即時処理する。ローカルで入賞番号は生成しない。
- 番号HITの消去 → 支持判定による落下 → 役判定 → 成立色を盤面全体から消去 → 落下・連鎖 → 全消し判定 → 上から元の10段まで補充。
- 役は従来の直線（同色4個以上）、トライアングル（同色6個）、ヘキサゴン（同色6個）。同じドロップの役重複は上位の役を優先する。
- 各役のn回目の配当は、直線0.10×n、トライアングル0.30×n、ヘキサゴン0.60×n（BET倍率）。役ごとに成立回数を数え、当該ゲームの配当へ加算する。例えば直線を3回成立させると0.10+0.20+0.30=0.60倍。配当表と判定はP/O設定に関係なく共通。
- 消したドロップ1個ごとに、そのときのBETの0.01倍をプログレッシブへ加算する。小数は内部で保持し、全消し時に整数メダルへ切り捨てて総取りする。
- 全消しで獲得してもプログレッシブ値は消費・リセットしない。その後も加算と全消し獲得を続ける。通常配当とは別に今回WINへ加算する。
- 当該ゲーム終了時に**シックスドロップ自身のWINが0**ならプログレッシブ・累計消去数・投入進行度を0に戻す。他ゲームのWINの有無には依存しない。
- メダル建てで個人別に持ち越し、BETを変更しても既存の蓄積額は換算し直さない。強制BETによる取消では開始前の蓄積へ復元する。

## 投入段数と色
初期盤面は10段としてカウントし、追加投入75個を10段分に換算する。新たに投入する球だけが段数に応じた色になり、盤面に残った球の色を勝手に変えない。

| 投入進行度 | 新たに投入する4色 |
|---|---|
| 0–9段相当 | 黄緑・緑・青・紺 |
| 10–19段相当 | 黄・黄緑・緑・青 |
| 20–29段相当 | 橙・黄・黄緑・緑 |
| 30–39段相当 | 赤・橙・黄・黄緑 |
| 40–49段相当 | 紫・赤・橙・黄 |

以降も8色の環を進める。上部には次の投入色、次の色変化段数、累計消去個数、現在のプログレッシブ額を表示する。右側は各役の成立回数・次回配当・獲得小計。遊び方デモも新ルールへ変更した。

## 落下方式
『世界のアソビ大全51』の6ボールパズルの見える支持・転がりを基準とし、既存の千鳥格子支持判定を新ルールにも共用する。単純な縦詰めにはしない。

- 左下・右下の2点に支持があれば保持する。
- 一方の支持が失われ、経路が開いていれば残った球の側面を回って斜め下へ落ちる。
- 両方が空いた縦穴では真下へ落ちる。横の隣球による転がり方向も判定する。
- 壁や球をすり抜けず、支持のある中空ヘキサゴンは保持する。支えのない空中の橋を固定しない。
- 複数球は衝突しない移動先を予約して同時進行する。描画と予測・精算は同じ着地点を使用する。
- 左右が完全に同条件のときの公式内部優先順位は確認できないため、既存の決定的なタイブレークを維持する。実機内部コードとの完全一致を主張するものではない。

## 配置と速度
P/O設定50–150に応じ、支持を外すと崩れる対称空洞テンプレートの採用率と近接色配置の確率を調整する。落下方向、役の配当表、ボーナス加算率は変えない。補充では残存ドロップの色・番号を保持し、上から到達できない穴を直接埋めない。完成済み役や宙に浮く球を初期・補充配置に残さない。

役成立の表示は180–260ms、連鎖の落下は1区間最大約300ms、上からの補充は最大580ms、全消しボーナス表示は720msを基準にする。非表示タブでは描画待ちを省いて計算と精算を進める。OSによるブラウザー完全停止中の実行を保証するものではない。予測は現在の盤面から確定する増加WINだけを出し、未抽選番号や将来の抽選は生成しない。

## 更新
Windows側の最新版更新と再起動、参加クライアントの再読み込みが必要。`.runtime`、`.tools`、`data`は維持する。Windowsサーバーは `start-shared-machine-tunnel.cmd` から再起動する。クライアントだけ更新した状態ではサーバーの持ち越し保存は更新されない。
