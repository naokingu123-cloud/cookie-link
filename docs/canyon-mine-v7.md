# Chocolate Canyon — texture and merge rules v7 (2026-10-29)

元の生成チョコ画像のツヤ・彫刻・外周の厚み・描かれたチョコ掛けを使用。v6の単色塗りの掛け部分を廃止。接続辺だけ共通の素材色へ滑らかに接続し、横の内部に個別マスの縁が残らないよう修正。描画先も半ピクセル単位にそろえて重なりや隙間を防ぐ。横長・L字・階段状の4色サンプルを実際の描画関数で確認。上下・左右の接続端16ケースの色と透明度を検証。

通常消去は「別の同色の塊と結合した瞬間に4マス以上」のみ。既に4/5/6マスある塊は、単に落下しただけでも着地しただけでも消さない。3+1や4+4の新しい結合は消去。ドリルによる直接掘削は従来どおり。

80ゲームと既存3ゲームのブラウザー回帰、5画面サイズ、1024オートタイルケース、番号更新・リーチ・HIT・秤・音声を検証。詳細 canyon-mine-v7-verification.json。実機iPhoneテストではない。
