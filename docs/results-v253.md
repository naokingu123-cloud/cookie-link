# v253 — 共通リザルトの登場・結果行・お菓子のカットイン

版: `20261119-v253-dango-tsukimi-results`。

参考動画の「結果ボードが登場し、参加ゲームの結果が並び、合計を示してから画面を切り替える」という構成を、SWEETS LINKの共通リザルトへ取り入れる。ゲームごとのロゴと金色の配当フォントを引き継ぎ、ボードと切り替え用のイラストは菓子を題材にした新しい生成画像を使う。

**検証状況：修正後の自動検証・画像レビュー・GitHub Pages公開確認が完了。** 対象コミットは `9e6433d99f75e85bcf10fb463bef1ebb57cae970`。横画面の浮遊ボタンの重なりを解消し、初回描画がすでに払い出し段階へ進んだ場合も即座に結果が読めることを確認した。実レポート、成果物のdigest、実行ID、公開検証は [`results-v253-qa.json`](results-v253-qa.json) に保存する。

## 表示の構成

既存の `#round-result-layer` と、その中の `.round-result`、参加ゲームの結果行、TOTAL WINを使う。別のゲーム結果を計算したり、演出専用の配当値へ置き換えたりしない。

- ボードは、焼き菓子・ウエハース・砂糖のリボンで縁取った巻物風の見た目で登場する。
- 各ゲームのロゴを左、実際のWINを右に置いた横長の行を並べる。BETしていないゲームは表示しない。
- Sugarを獲得したゲームだけ、その行のWIN付近にSugarの獲得表示を添える。
- 下部のTOTAL WINには、既存のラウンドが集計した合計を表示する。数字は共通の金色配当フォントを使い、コンマを入れない。
- スマートフォン縦画面は1列で表示する。高さが限られる横画面では、参加ゲーム数に応じて横長の結果行を2列へ分け、全ゲームと合計を画面内に収める。
- 通常の結果終了時には、クッキー・団子・クリームなどのお菓子のイラストを短いカットインとして表示する。

生成画像は `assets/results-art-v253/result-frame.webp` と `assets/results-art-v253/sweets-wipe.webp`。生成指示、画像寸法、ファイル容量とSHA-256は [`results-v253-assets.json`](results-v253-assets.json) に保存する。既存のゲームロゴは `assets/arcade-v249/` の素材を使う。

## 演出とラウンド進行の分担

共通結果画面には従来の8秒の表示タイマーがある。一方、共有抽選機では払い出し完了を受けた制御が先に結果を終了する場合があり、結果が8秒表示されることは前提にできない。配当0のときは、従来の約1.8秒の結果段階が最短の目安になる。

そのため、登場は約450 ms、結果行は約1秒までに順次表示し、合計は約1.3秒までに読める状態にする。表示する数字そのものは最初から実際の結果を入れ、各行と合計の出現だけを演出する。既存の結果段階、CREDITへの払い出し、完了判定、自動進行の時間は変更しない。

カットインは、既存処理が結果レイヤーを実際に閉じて次のBET待ちへ進んだことを観察して始める。結果レイヤーとは別の約650 msの表示で、`pointer-events: none`、`inert`、`aria-hidden` を付ける。カットインのために結果画面を再表示したり、次ゲームへ進む関数を呼んだり、BET待ちを遅らせたりしない。

結果の描画が同じラウンドの中で更新されても、登場演出は繰り返さない。新しいラウンドの結果になったときだけ、最初から再生する。

## 一時停止・非表示・動きを減らす設定

メニュー表示、アプリの一時停止、ページの非表示では登場演出の時計を止める。同じ結果を再開するときは途中から続ける。非表示の間に共有制御が結果を片付けた場合、復帰時に古いカットインを再生しない。

メニュー、JPC、すでに次ゲームが始まった状態などでは、退出のカットインを省く。OSやブラウザーの「動きを減らす」設定では結果行と合計を最初から表示し、退出の移動演出を行わない。

結果画面またはカットインの表示中は、既存の「SERVER待機」「JPCモード」の浮遊ボタンを非表示にし、結果やWINを遮らないようにする。演出が終われば表示を戻す。MENUはこの対象に含めない。

表示の追加コードは `assets/sweets-results-v253.js` と `assets/sweets-results-v253.css`。状態確認用の `SweetsResultsV253.describe()` は、現在のラウンド、演出段階、経過時間、表示行、合計、停止状態、カットイン状態を返す。ゲームの結果やCREDITを書き換えるためのAPIではない。
