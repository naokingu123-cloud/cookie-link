## デザイン

ユーザー提供のゲーム選択画面とプレイ動画を参考に、太い立体文字、白・金の縁、光沢のあるお菓子、鮮やかな色分けを9ゲーム共通の見た目へ展開した。動画の「選択中はロゴ、別のゲームは動くミニ盤面、獲得時にタブ内で大きな金色の数字」を現在の9ゲーム構成へ取り入れている。

新ロゴはすべて既存の日本語ゲーム名で制作した透過画像。画像生成ツールで制作後、表示用に768×384のWebPへ変換した。9種類の合計は1,015,074バイト。正確な生成プロンプト、寸法、SHA-256、ファイル名は [arcade-v249-assets.json](arcade-v249-assets.json) に保存している。

## タブ

- 選択中の「選択中」表示を新しいロゴへ変更し、タブ上部を広く使用する。
- 非選択タブは既存のライブミニ盤面を維持し、ロゴ見出しを拡大する。
- 9ゲームの5列×2段、BET・リーチ・WINの操作と情報を維持する。
- 選択状態・表示中の盤面は元の処理で直ちに変更し、約220msの短い移動とフェードを重ねる。タブには約210msの弾みを付ける。
- 連打時は前の装飾アニメーションを取り消し、最後の選択へ収束する。非表示・ページ終了・動きを減らす設定にも対応する。
- 実際の表示WINが同一ゲーム内で増えたときだけ、タブ内に `+n WIN` と星を約680ms表示する。既得配当の復元、同じ金額の再描画、再選択だけでは獲得演出を発生させない。
- 同じ金額を毎回旧サイズと新サイズで二重に整形する処理を避け、表示額・選択状態が変わるときに調整する。

## ゲーム画面と演出

ゲーム別に背景、筐体の縁、配当プレートの素材と色を調整した。既存の盤面やキャラクター素材を活かし、全体へのぼかしではなく、白・金・各ゲーム色の縁と短い影で奥行きを付けている。

実際のHIT・連鎖・掘削・MIX・ビンゴ・反転・焼成・全消しなどの通知に合わせ、表示中のゲームだけに短いフレーム発光と素材別の欠片・泡・結晶・星を出す。装飾は各盤面に作成済みの1レイヤーと12個の粒を再利用し、操作を遮らない。先に計算された結果から配当演出を早出ししないよう、各ゲームの実際の表示境界で反応させる。

シックスドロップのキャンディ瓶と「全消し nWIN」、共通配当フォント・右寄せは維持する。抽選・落下・盤面生成・BET・配当計算・サーバー色判定・保存形式はv248と同じ。ゲーム名も変更しない。

## 検証

`tests/arcade-visual-v249.mjs` は既存の実サーバー・実9ゲーム検証に表示観測を追加する。全ロゴの読み込み、390px／1366pxでの9画面、430pxでの高速切り替え、横画面、キーボード操作、動きを減らす設定、操作領域、盤面とコンソールの収まりを検査する。実抽選中の表示切り替えと、非表示ゲームの処理継続も確認する。

```sh
npm run check
npm run test:sixdrop
npm run test:arcade
node tests/client-hidden-browser-v246.mjs
node tests/sixdrop-hud-v247.mjs
```

新しい役配当欄の読みやすさは、従来の背景色との一致ではなく、3枚の実際のグラデーションの色に対する文字・金額のコントラスト、文字サイズ、共通配当フォント、右寄せ、数字の途中値で検査する。
