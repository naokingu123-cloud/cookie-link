# ダンゴデビンゴ v262：7段盤面と50〜150％の配当調整

公開版識別子：`20261119-v262-dango-payout`。

2026年11月19日の「配当はかえてもいいので実装して」という指示を受け、試験版の配当見直しを本番に採用する。配当は全P/O設定で共通。通常ゲームのオッズアップを含む理論払戻率を、初期配置の混合比で50〜150％へ調整する。

## 採用配当

表はODDS×1でのBET倍率。同じ長さでは完成した本数に対応する段を一度だけ採用し、異なる長さの賞は合計する。その合計に現在のODDSを一度掛ける。

|ライン長|1本|2本|3本|
|---|---:|---:|---:|
|3個|0.1倍|0.3倍|7.5倍|
|4個|0.3倍|1.5倍|7.5倍|
|5個|0.8倍|4倍|30倍|
|6個|1.5倍|15倍|75倍|
|7個|4.5倍|40倍|2,000倍|

2,000倍は7個ライン3本の基礎配当であり、ODDS適用後の上限ではない。通常役は元案から大きく下げている。これは元案の配当とオッズアップ、最適な手動配置を全て維持したままでは50％に届かないためで、元案の約104.58％という試算にはオッズアップ等が含まれていなかった。検討経緯は `dango-v262-trial.md` と較正資料に残す。

## 盤面とFREE

- 盤面は上から1・2・3・4・5・6・7マス、合計28マス。番号1〜25を一つずつ配置し、残り3マスは初期FREEとして最初から成立済み扱い。
- 横と2方向の斜めに、3〜7個ラインが各3本。長いラインの途中の短い部分列を追加のラインとして数えない。
- 初期配置と、1〜25から重複しない3つの拡張番号は抽選開始前に確定する。拡張番号は画面に表示する。
- 前半5球での拡張番号HITが0／1／2／3個なら、シンキングで置く範囲は0／1／7／17マス。中心もFREEに含む。
- 2個HIT時は中心と隣接6マス。6方向の隣接マスがある中心だけを選べる。
- 3個HIT時は中心と盤面内の近い16マス。端でも17マスを保ち、同じ距離の候補には固定した順序を用いる。選択候補にフォーカスすると、実際の範囲を表示する。
- 前半に番号HITしたマスは中心に選べない。初期FREEの上は中心に選べる。選択中の中心をもう一度押すと取消し、別の候補を押すと置き直す。

## ODDS UP

倍率は次の条件から毎回再計算する。

`ODDS = 1 + 置いた範囲に含まれる初期FREE数 + 後半3球で配置FREEにHITした数`

シンキングで初期FREEに重ねたマスごとに＋1、後半に配置FREEへHITした球ごとに＋1。前半の拡張番号HITだけではオッズアップしない。前半のHITに範囲が重なっても、過去のHITへ遡って倍率を加算しない。

取消し・置き直し・同じ球の再送・保存復元では、倍率や払戻しが増殖しない。配当表の金額、予測、WIN、サーバー精算には同じルールを使う。

## 50〜150％の較正

番号のシャッフルと初期配置の選択は、実際の抽選開始前に行う。後半の入賞番号を見て中心を選んだり、払戻しを後から減らしたりしない。

|初期配置|初期FREEのセルID|拡張番号を割り当てるセルID|AUTOの理論P/O|
|---|---|---|---:|
|すその三粒|0, 20, 22|8, 11, 12|47.5326909170％|
|三色まつり|6, 9, 24|10, 23, 25|246.8507418084％|
|三角の祝宴|0, 2, 21|3, 10, 15|197.0871425930％|

セルIDは上の段から左→右の0始まり。「三角の祝宴」は全設定で1.5％とし、残る98.5％を最初の2型で配分する。固定分を含む下端は49.7760076922％、上端は246.1042878202％なので、50〜150％の全範囲を含む。

目標をT、各型の理論P/OをL・H・Jとすると、強い型の割合は `(T − 0.985L − 0.015J) / (H − L)`。弱い型は `0.985 − 強い型の割合`。101個の整数設定を厳密な整数比で照合し、小数設定にも同じ補間を使う。

AUTOは前半5球だけから、後半3球の全1,140通りに対する条件付き期待配当が最大になる中心を選ぶ。第3型では7個ライン3本の2,000倍役もAUTOで到達できる。具体例は、番号を昇順に並べた第3型で前半が1・2・5・9・14、AUTO中心がセル27。1.5％の固定混合を含む理論上の成立頻度は、全設定で約375,547ゲームに1回。

この数値は1〜25から一様な非復元8球抽選を仮定した、ダンゴ通常ゲーム単体の理論値。共通Sugar・JPCと整数メダルへの丸めは含めない。手動で期待値最大の中心以外を選んだ場合や、物理抽選の番号頻度に偏りがある場合は一致しない。有限回の実測払戻率が毎回設定値に一致する意味ではない。

## 保存と更新

Streamingの手動配置とDownloadのサーバーAUTOを維持する。6球目を処理する前に中心を確定し、保存状態に中心・範囲・拡張番号・ODDSを含める。revision251・253・254で始まったゲームは、旧25マス盤面と保存時の配当で再開する。試験版revision262で始まったゲームも、その保存済み配置と同じ配当を保つ。

公開版では版情報と入口のキャッシュキーを更新し、Download用の全資産のサイズ・SHA-256を再生成する。旧Download版と試験版のキャッシュを、保存済みゲームの再開用に保持する。

Windows共有サーバーのローカルファイルはPages公開だけでは更新されない。最新mainのソースを反映し、既存の `.runtime`・`.tools`・`data` を保持して従来のランチャーから再起動する。

- `npm run test:dango:current`：現行の盤面・配当・ODDS、全101設定、AUTO、保存復元、旧ルールdispatch。

- `scripts/dango-v262-calibrate.cpp`：JavaScriptと独立した整数計算で、各型と混合比を全列挙。出力を `tests/dango-v262-calibration.mjs` へ渡して照合する。
- `tests/dango-v262-view.mjs`：盤面・15配当セル・旧画面・FREE範囲・取消しを実ブラウザで検証。
- `.github/workflows/dango-v262.yml`：上記に加え、実サーバーの10ゲーム計算、Download途中再開、オフライン再生、二重精算防止を確認。
