# v242 — 1画面の管理画面・強制BETと全額返却・推移グラフ

## 管理画面
上段を抽選機、縮小した設定欄、推移グラフに分割する。下段は合計行とst.1〜6。在席者の名前/ID、BET、WIN、CREDIT、IN、OUT、H/G、実測P/O、設定P/O、補正P/O、1〜25番予測、制御、球数、状態、詳細を表示する。25番号は13+12の2段。メイン画面には縦横のスクロール欄を作らない。詳細設定と過去の全プレイヤー台帳はダイアログで表示する。合計行の累計は過去のプレイヤーも含む。狭い画面では文字が非常に小さくなるので、管理は横長PC画面を推奨する。

## 強制BET・全額返却
管理者ボタンは現在のラウンドIDと操作IDに結び付く。抽選途中でも現在のゲームを取り消し、全参加者のBETをサーバー残高へ1回だけ返却して新しいBET TIMEを開く。予約待ちではない。現在ラウンドの途中WINは無効。切断中に既に0WIN精算した人も返却する。現在ラウンドでWINが精算済みの場合、そのWINとIN/OUTへの加算を取り消してBETを戻す。完了した過去の別ラウンドは変更しない。

同じ操作IDの再試行は二重返却しない。画面のラウンドIDが既に変わっていれば新しいゲームを誤って取り消さず、再操作を求める。取消後の旧入賞、チェックポイント、精算は拒否する。残高の取消記録を先に永続保存し、コア保存前のクラッシュからも復旧する。払い出し推移とPO調整のIN/OUTには返却分を加算しない。

クライアントは旧ゲームの処理を無効化し、本人のサーバー残高を確認して表示を更新する。返却直後のBETに限りAUTO REBETによる即時再引き落としを抑止する。再参加は「BETする」。AUTO REBETの保存設定自体は変更しない。通常の以後のラウンドは従来通り。

## グラフ
横軸はゲーム番号と精算時刻。左軸は累計IN/OUT（メダル枚数）、右軸は実測P/O（%）。追加でH/Gと直近10GのP/OをON/OFFできる。直近30/60/120Gを選択できる。精算時にサーバー台帳と同じ保存処理で記録し、再起動で消えない。複数プレイヤーの精算は1ゲームへまとめ、遅れた精算は同じ点を更新する。全員精算前は「精算中」。取消ゲームは除外する。既存台帳で復元可能な直近ラウンドを初期表示し、それ以前の累計を基準値に含める。追加の抽選や予測シミュレーションは行わない。Canvasは値・表示設定・寸法が変わった時だけ再描画する。

## 更新
Windows側を更新し、.runtime/.tools/dataを保持して再起動。管理画面・ホスト・全参加者のクライアントを再読み込みする。公開ページだけの更新ではWindowsの返却処理は変更されない。OSによるアプリ完全停止はブラウザ継続と同義ではないが、返却自体はサーバーへ保存され、再接続で反映される。
