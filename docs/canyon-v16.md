# 300m到達率を約5%へ

0mから配当を獲得して継続し、累計300mへ到達する割合を約5%へ引き上げる調整。各ゲームは8球、無配当で探索終了、配当有で深度継続という規則はそのまま。

少額の銅鉱石を増やして継続しやすくし、銀以上・ランクアップの出現と銅の配当内訳で直接配当率を調整する。

- 鉱石候補の基礎率：銅 .25、銀 .002、金 .0004、ダイヤ .0001、ランクアップ .0008。
- そのゲームで60m進むまでの差分：銅 -.004、銀 +.001、金 +.0003、ダイヤ +.0001。
- 銅の配当：0.1倍84%、0.2倍16%。他の鉱石の配当範囲・刻みは変更しない。
- 生成鉱石と鉱石化アイテムは同じ配当抽選を使用する。
- 全消し・3セクション消し・鉱石化の候補率、累計mボーナス、回収条件、ランクアップ、画面配置は変更しない。

継続全体が容易になるため、以前約19%だった100m到達率も上昇する。到達率の分母は0m開始から無配当終了までの「終了した探索」。配当率は共通シュガー/JPCを除く直接配当で、累計mボーナスを含む。

再現：`node .github/tests/canyon_rtp.cjs 50000 612937`
