# v241 管理画面：台帳・25番号の次入賞予測

列は、プレイヤー（名前・ID）／BET／WIN／CREDIT／IN／OUT／H/G／実測P/O／設定P/O／補正P/O／1〜25番／制御／球数／状態／詳細。

INとOUTは既存の確定累計BET・WIN。H/GはIN−OUTで負数も表示。実測P/OはOUT÷IN（INが0なら未算出）。設定P/Oは全体設定、手動で個別設定した場合は個別値。補正P/Oは現在のサーバー応答のeffectiveRate。今回、実際の設定・配当計算・口座更新方式は変更しない。

各番号の上段は次の1球で増えるWIN、下段は増加WIN÷現在の合計BET。例：27000BET、+2700WINなら+0.1倍。既存の次入賞予測キャッシュを利用し、追加の25通りシミュレーションは行わない。各ゲームで丸めた後に合計する。

色は増加倍率そのものではなく、入賞後の総WIN÷合計BETが初めて帯域に入る場合：3倍以上10倍未満は赤、10倍以上50倍未満は紫、50倍以上は虹色。2→3は赤、3→8は通常、9→10は紫、49→50は虹。入賞済み、予測更新中、未BET、終了後を区別し、未取得を0扱いしない。

合計行は一覧の先頭に固定。BET/WIN/CREDIT/IN/OUT/HGを加算し、実測P/Oは合計OUT÷合計IN。設定/補正P/Oは現在BETの加重平均（BETが0なら未算出）。番号予測は対象全員の最新値が揃う場合のみ合算し、一部欠落時は更新待ちとする。横に長い表はスクロールでき、名前列・見出し・合計行を固定する。

右上の数値概要カードと全体ゲーム別グラフを削除し、設定上限・下限など7入力と保存ボタンは維持。各人の詳細設定、BET TIME開始、左側6席、非アクティブ継続、最高役リーチ色は維持。

25番号のデータは認証済みの本人通知を受け、管理者スナップショットだけに返す。ラウンド/球数が不一致、切断、精算後、12秒以上古い場合は破棄。公開の参加者名簿には25番号配列を含めない。サーバー側では予測を信用して口座や抽選を変更しない。

Windows側は更新して .runtime/.tools/data を残し、start-shared-machine-tunnel.cmd で再起動。管理画面と参加者全員のクライアントも再読み込み。旧クライアントは25番号予測を送信しないため、更新待ちとなる。
