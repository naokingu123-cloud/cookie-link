# v276 キャニオンの上下オートタイル

## 原因

v275 のケーキ画像は、上面のクリームが画像の高さ約45%まである。従来のサンプラーは上に同色がある場合に34%から読み出すため、つながった地層の途中に上面が残っていた。また、上下の接続帯は中央部を1画素の色で広く埋めていたため、描き込まれたスポンジの模様が帯状に途切れていた。T/L字の分岐では、上のセルと下のセルで左右の隣接状態が異なるため、接続端の側面プロファイルも一致していなかった。

## 修正

- `assets/illustrated-boards-a-v275.js` が新しい4枚のケーキ素材に本体範囲（50～94%）と接続部のサンプル範囲を付ける。生成PNG、旧素材や宝石の入力は変えない。
- 上に同色があるマスはスポンジ本体から読み、上端が露出した場所だけに元のクリーム・飾りを残す。
- 上下の接続は、元画像の模様を横幅全体から読み、同じ方向で連続するサンプルに18pxでなじませる。単色の帯を上描きしない。
- T/L字の接続端は斜めの隣接ビットまで使い、上下のセルが同じ側面を参照する。
- フルーツボーナスの虹色グレーズも、上下のつながる端で同じケーキ面へなじませる。左右の装飾グラデーションは従来どおり。

47種類の8近傍マスク、6種類の表面バリエーション、内角・外角、既存のキャッシュキーと画像参照関係を保つ。配置、ゲーム状態、抽選、配当、融解や落下の制御は変更していない。

## 検証

`tests/canyon-autotile-v276.mjs` は QA 専用の `@napi-rs/canvas@0.1.100` で、生成済みPNGを実際の描画関数へ読み込む。

- 通常4素材＋フルーツについて、それぞれ上下2セル周囲の1024配置、合計5120組を比較。接続端のRGBA差は0（内外角用の端4pxを除く）。
- 左右の上・下の隣接状態4種類と表面バリエーション6種を比較。通常4素材の左右接続端の差は0。
- 47正規化マスク、表面の描き込みの差、キャッシュ再使用、12の内外角条件を確認。
- 6種類の既存宝石×47マスク＝282スプライトの描画を確認。
- 上下接続端の中央40画素は24色以上あり、単色の帯になっていないことを確認。
- 入力画像の画素ハッシュは描画の前後で一致。

テストは配信用 `optimized/app-01.js` と元ファイルの描画関数の一致も要求する。`--source-only` は編集中の元ファイル確認用。実描画による縦列、T/L字、内角の図は `qa-canyon-v276/vertical-junctions.png`、集計は同ディレクトリの `report.json` に出力する。
