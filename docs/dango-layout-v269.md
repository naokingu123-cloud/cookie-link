# SWEETS LINK v269 — FREE確定時刻と盤面レイアウト

公開識別子: `20261120-v269-dango-layout`

## シンキングタイムとAUTO

配置FREEは、6球目の入賞を待たず、シンキングタイム終了・6球目発射時に確定する。AUTOはその時点までの5球だけを使い、手動配置済みのFREEを維持して残数を補完する。

- 共有版はサーバーのシンキング期限で表示と配置を即時確定し、既存の保存・受信バリアで5球時点の状態を保存する。保存ACKや別ゲームの演出待ちでAUTO表示を遅らせない。
- ローカル物理抽選は、既存の待機時間と発射可否判定を通過した6球目の発射直前に確定する。物理抽選の速度・番号・発射間隔は変更しない。
- ローカル番号指定は、6球目を選ぶ直前まで配置できる。架空の時間制限は追加しない。
- ダウンロード再生は、5球目の入賞後にある最初の発射時刻を境界にする。参照するのは録画の時刻であり、6球目の入賞番号ではない。5球途中からの再開にも同じ境界を適用する。

## 8球後のリーチ

最終盤面に対して表示用リーチを再計算する。7球時点の候補を残す処理ではない。盤面・ミニ盤面・タブ・配当表に使い、通常の抽選用リーチとは分離する。

`DangoBingoRules.presentationReaches`は盤面を変更しない投影であり、9球目を追加しない。8球終了後の通常の`reaches`は空のまま。確定配当、入金、v268の配当設定と初期FREE較正には変更を加えない。

## 配当表と演出

配当表は左上へコンパクトに配置する。配当数字の高さをv268から維持し、不要な横幅を詰める。長い金額は横方向だけ圧縮する。

前半は「3本」列の右側に別枠を設け、各行に2〜7個の黄色いFREEだんごを実際の画像素材で表示する。行見出しの`FREE×n`文字は撤去する。画面の高さに応じて1段または2段に並べ、数字の列を引き伸ばさない。5球目の結果が出てシンキングタイムに入った時点で、これらのFREEマークをすべて隠す。

メイン盤面のリーチ枠は明滅の振幅、光の広がり、線の太さを抑え、リーチ文字を小さくする。最高役6種類の虹枠、GET!、配当リーチ、0配当の`-`、2個ラインの青・3個ラインの水色は維持する。

## BET切替

既存の共通BET切替をルーレット右下へ移し、BETを編集できる時間だけ表示する。抽選中・シンキング中・結果表示中は非表示にし、プログラムからクリック処理を呼んでも変更できないようにする。共有版の登録・締切ロックと、ダウンロード準備以後のロックを尊重する。

下部のBET切替用スペースを撤去し、BET・WIN・CREDIT表示と履歴へ戻す。フッターは78から66論理pxに詰め、メイン描画領域にも高さを戻す。長い金額は既存の数字フィッターで横方向に収める。
