# デバッグ用ペイアウト率設定 v26（2026-10-30）

MENU内の色設定・キャニオン深度設定の左に「目標配当率」を追加。50〜150%を1%単位で指定し「設定」を押す。初期値90%。全3ゲームに適用し、同じ端末・ブラウザに保存する。BET TIME中だけ変更でき、次のゲームに使う盤面を再生成する。獲得済みシュガーと持ち越しハンマー、キャニオンの累計深度は保つ。

## 調整する内部要素

- **クッキーリンク**：数字候補マスの高さ・1マスが消えた場合の連鎖の起こりやすさで配置を重み付け。獲得済みハンマーの配置も、既存の数字から連鎖に巻き込まれやすい候補へ確率的に寄せる。ハンマーの色・個数・獲得条件は変えない。将来の抽選番号は使わず、現在の盤面だけで候補を評価する。
- **キャニオン**：鉱石・アイテムの生成密度と、銀以上の鉱石の比率を調整。鉱石の配当確率表、ランクアップの規則、100mごとのボーナス額は固定。
- **シックスドロップ**：生成時の色の分散・まとまりやすさを調整。初期・補充時に4個以上の消去が発生しない制約、左右対称の数字配置、安定した初期盤面は維持。

抽選機の番号・共有の抽選列・配当表・全消し倍率・実際に成立した役への支払い額は変更しない。全3ゲームとも、通常の生成候補の選び方を調整する。重みには上限を設け、確率的な選択を残している。

設定値の間は係数を区間ごとに線形補間。90%設定では追加の乱数消費を行わず、v25の盤面生成とゲーム結果が固定seed試験で完全一致する。実装は `assets/debug-economy.js`、各ゲーム本体にも呼び出しを組み込んでいる。

## 試算

| 設定 | クッキーリンク | キャニオン | シックスドロップ |
| --- | ---: | ---: | ---: |
| 50% | 48.69% | 51.84% | 48.73% |
| 90% | 90.08% | 89.57% | 88.70% |
| 110% | 112.84% | 108.50% | — |
| 150% | 149.39% | 153.84% | 148.27% |

50%・150%のクッキー／キャニオンは各1万ゲーム、シックスは各5千ゲーム。110%はクッキー5千、キャニオン1万。90%のクッキー／キャニオンは生成処理が一致するv25の各10万ゲーム統計を引き継ぎ、シックスは5千ゲーム。

目標値は通常5色・一定BET・一様な8/25抽選における通常ゲームの長期目安。手動番号指定、3色・4色のデバッグ設定、極端な深度指定では同じ率を保証しない。短期間の実績は変動する。共通ワンダーシュガー／JPC配当は集計対象外。設定を変えるとキャニオンの継続率・300m到達率も変わる（約5%の到達率は90%設定での基準）。

## 検証

- `debug_economy_rules.cjs`：90%の固定seed結果がv25と一致。評価処理が盤面を変更しないこと、50〜150%の率が有限・非負で総和1未満、数字25個の重複なし、配当定数固定、単体ソースとHTML内埋め込みの一致。
- `debug_economy_browser.py`：320／390／1280px幅、色設定より前に配置、50／90／150%適用、空欄・49・151・小数の拒否、ゲーム中変更禁止、再読込後の設定維持、配当表不変。
- Canyon80ゲーム・Six36盤面等の既存ルール試験を通過。統計実行でも全ゲームの解決が正常に完了。
