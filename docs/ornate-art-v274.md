# v274 — 元の質感を生かした盤面・配当枠

版: `20261120-v274-ornate-game-art`

ユーザーの追加指示は「背景はもとのまま」「盤面や配当表をよりこったアニマロッタ調の画像へ」「前に生成した画像を流用してよい」。さらに、シックスドロップのドロップは変更前の描き込みが適切との指定を受けた。

## 反映内容

v272/v273 の単純化した共通画材と A/B/C アダプターを入口から外し、v271 までの元のピース・背景・ガラス・光沢・奥行き表現を復帰させた。旧アダプターのファイルは履歴と旧版キャッシュのため保存するが、新しい入口からは読み込まない。各 view の既存フォールバックが元のレンダラーを使用する。

新規生成した画像は枠専用。クリーム、果物、金細工、宝石、焼き菓子、漆、桜などをゲームごとに描き分けた。背景と数字は画像へ焼き込まず、元の背景と実際の数値表示を保つ。

## 画像と実装

組み込みの `image_gen` で透明 PNG アトラスを3枚生成した。いずれも1536×1024、3列×2行。生成後はプロジェクトへ原寸のままコピーし、元の RGBA ピクセルを保持している。最終プロンプト一式は `ornate-art-v274-prompts.json`。

- `assets/ornate-art-v274/board-frames-a.png`: Cookie、Choco、Six、Gelato、Winery、Popcorn。
- `assets/ornate-art-v274/board-frames-b.png`: Jelly、Waffle、Castella、Dango、Sugar、Bonus。
- `assets/ornate-art-v274/payout-frames.png`: Cookie、Choco、Six、Gelato、Winery、Jelly。

`assets/ornate-art-v274.js` は18枠の読み込み、余白の計測、9分割描画、CSS用画像 URL のキャッシュだけを担当する。中心を描かないため、元の背景を覆わない。描画処理にゲーム乱数や配当計算を入れていない。読み込みに失敗した場合は元の画材を使う。

`ornate-art-v274.css` は外枠を配置する。`ornate-boards-a/b/c-v274.css` と A 用 JS は既存の内側の配当家具に装飾を接続する。Jelly の配当枠は `sweet-frames.js` の限定分岐から描く。盤面の寸法、padding、マス位置、タッチ領域、番号、フォント、配当の座標、保存や同期の規則は変更しない。

シックスの描画経路は v271 と同じ `sixCandySprite → v247 sixArtCandySprite → paletteSprite → nativeSprite → candies.webp`。元画像とその描画コードは v271 基準コミット `81a83d3` との差分がない。

## 検証

- ローカルの構文チェック、全ゲーム配当テスト、Sugar のルール・確率・台帳・サーバー・倍率表示テスト、Download cache テストを実施して成功。
- ダウンロードマニフェストは672ファイル、158,598,295 bytes。全ファイルの SHA-256 とサイズが一致することを確認。
- 管理されたプレビューを実ブラウザーで開き、通常画面のシックス、クッキー、ワイナリー、ジェラートを確認。元の画像と背景、および新しい装飾枠の表示を確認した。
- 全10ゲームの開始前デモ・プレイ中・小窓・スマートフォン幅・状態不変を検証する CI は `tests/ornate-art-v274-browser.mjs`。v272 の簡略素材を要求する旧期待値を、元の素材と18枠の組み合わせへ更新した。
- Dango の v269/v266 表示テストは、元の団子・台と黒い v270 配当表の実描画を検査する。配置、虹、FREE、GET、中央金額、状態不変の検証は保持した。

この確認ブラウザーは WebGL を利用できないため、目視確認はローカル版の番号指定モードで行う。3D抽選機自体の描画は今回の変更対象・目視検証対象に含めていない。公開された共有サーバーへ BET・抽選・精算を送らず、CI は隔離したサーバーを使用する。

v271 の Sugar 条件（混合成立率9.94993835048755%、JP横の×n、はずれ配当は倍率なし、6.25秒の倍率リール）は維持する。旧ルールで作成済みの保存カードは従来どおり互換性を維持して再開する。

公開後の検証結果と画面記録は `ornate-art-v274-public-qa.json` と `qa-v274/` へ記録する。
