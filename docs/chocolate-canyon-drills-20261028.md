# チョコレートキャニオン：7列ドリル版

## ルール

- マスには数字を配置しない。盤面は7列×12段、初期・次ゲームは84マス。
- 各列のドリルに3番号を付与。1〜25をシャッフルし、21番号を7列、3番号をラッキーナンバー、残り1番号をHITなしへ割り当てる。番号は重複せず、ゲーム中は固定。
- 列の番号に1つHITするごとにその列のレベルを1段階上げ、上がったレベルでその列を掘る。同じ番号の再通知は無効。
- ラッキーの最初の2番号は、各々全ドリルを＋1レベル（強化のみ）。3つ目は現在レベルで全7列を同時に掘削。未HIT・未強化列も、その発動だけはLv.1相当で1マス掘る。
- レベル＝その列のHIT数＋全体強化数、最大5。待機中はLv.0。

| レベル | 素材 | 掘削量 |
|---|---|---|
| 1 | 鉄 | 1マス |
| 2 | 銅 | 2マス |
| 3 | 銀 | 4マス |
| 4 | 金 | 8マス |
| 5 | ダイヤ | 12マス |

- 掘削量は、その列の上から存在するマスを数える。空洞は数えない。同色の塊全体はドリルの直接破壊には巻き込まない。
- 3・2・1・1・1球の抽選は維持。各組の番号を入賞順に処理し、同じ列の複数HITも順に強化・掘削する。
- 各掘削後、塊の落下・同色合体→全落下完了→露出配当・4個以上の同色連鎖。組の処理終了後に上端の空行分をせり上げ補充し、その場で補充連鎖は起こさない。
- 銀0.2倍、金1.2倍。配当ありなら深さを継続、なしなら0m。次ゲームは全盤面・ドリル番号・ラッキー番号・レベルを初期化。
- 途中リセットは開始時チェックポイント（番号とLv.を含む）に復元。旧保存データの深さを移行し、新盤面とドリルを生成。

## 表示

各列上部に3番号・HIT済みチェック・立体的なドリル・Lv.・掘削マス数。鉄/銅/銀/金の金属光沢と、ダイヤの青い多面反射を描き分ける。右にラッキー3番号と5段階の素材・威力一覧。掘削時はドリルが列を下り、全体強化/全列発動を別の告知で表示。メインと小盤面は同期。描画はゲームの乱数・状態を変更しない。

## 配当率

出現率は銀2.56％・金0.468％（初期上2行には配当なし）。新規seed 281028521 / 281028522で各20,000ゲーム。通常8球の順序・5組処理・次ゲーム生成・勝利時の深さ継続を本番の関数で再現。

平均 **89.6070％**。500ゲーム×80バッチからの参考95％区間 **88.68〜90.53％**。JPCとBET別の整数丸めは含まない。

## 検証

- 1/2/4/8/12マス、同色の隣マスを巻き込まないこと、空洞を飛ばすこと。
- 番号の25個一意割当、列3HIT、全体2強化、最大Lv.5、全列同時発動、未HIT列、重複通知、組内の処理順。
- 80ゲームの8球通し、配当の一度払い、落下完了後の連鎖、次ゲーム初期化、0BET、保存移行、途中リセット取消、演出中の追加入賞。
- Chromiumで320/390/430px・横向き・PCサイズ、5素材の描画差、番号/ラッキー/レベル表示、全7列のドリル演出、画面内の配置、配当文字の非クリップ、描画による乱数/状態の非変更。
- 既存シックスキャンディの回帰テストと3ゲーム集計、3D抽選機初期化も確認。変更はチョコレートキャニオン専用JS/CSSに限定。
- iPhone実機・スピーカーの聴感・自然物理の全8球は未検証。
