# v257 — download_player_mismatch 修正

既存のプレイヤーID・トークンが失効していた場合、従来の /api/session は新IDを発行し、旧IDを保持するブラウザー側が download_player_mismatch で停止していました。静的なゲーム素材のダウンロードができても、プレイヤー認証は完了していません。

修正版は、プレイヤーID・トークンが保存されている場合に、サーバーの認証済みプロフィールAPIを先に照合します。成功時は元のID・CREDIT・成績を保持したまま開始します。失敗した場合には同一の既定公開サーバーで有効な旧ストリーミング版の資格情報を一度だけ確認します。保存済みの録画がある場合、プレイヤーを切り替えません。

いずれの資格情報も無効なら、元のCREDITと録画を消さずに認証エラーを表示します。別の新規プレイヤーとして始める場合は、元のデータが引き継がれないことを確認するボタンを明示的に押す必要があります。元の認証情報はバックアップし、端末の録画とサーバーの台帳を消しません。

サーバー /api/session も strictIdentity:true を受け付けた場合、失効したID・トークンから自動で別のIDを作らず401 download_identity_invalidを返します。既存ストリーミング版のログイン動作は変更しません。
