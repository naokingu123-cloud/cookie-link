# チョコレートキャニオン：オートタイル・拡大盤面

- 生成済み4種類の画像を8近傍・4分割のオートタイルとして描画。同色の上下左右は内部境界をなくし、外角・直線・内角を描き分ける。斜めだけの接触はつながらない。
- 表面の色を連続させ、内部のマス目の線を除去。元画像の艶・角の模様・外周のケーキ層を残す。キャッシュで再利用し、ゲームの乱数や判定を変えない。
- 縦画面ではゲーム領域を390から450px、盤面領域を312から384pxへ拡大。重複説明帯を除去し、実際のキャンバス縦横比から7列12段の正方形が最大になるサイズを計算。ミニ盤面も比率維持。横画面は既存の領域内で最大化する。
- 次ゲームでは初回と同じ生成方法で84マスをすべて新規生成し、1〜25を1個ずつ配置。配当ありなら深さだけ引き継ぎ、配当なしなら深さも0mに戻す。保存後の再開も同じ初期盤面生成を使用。
- ゲーム途中の3/2/1/1/1抽選、落下後4個消去、せり上がり時の一部未抽選番号補充は維持。
- 銀0.2倍・金1.2倍を維持。毎ゲーム新盤面となる影響を補正するため銀の出現率を4%に調整（金0.73%）。

## 統計

最終seed 281028421・281028422、各20,000ゲーム。実装と同じ生成・抽選・消去・落下・新ゲーム生成を使用し、配当獲得時の深さ継続も再現。

平均配当率 **90.0495%**。500ゲーム×80バッチの平均からの参考95%区間 89.13〜90.97%。JPCとBETごとの端数処理は除外。

## 検証
