# Chocolate Canyon — mine v4 (2026-10-29)

7列・各列1番号。初期Lv.1。列番号HITで現在Lv.と同数の地層を1本のドリルが連続掘削し、終了後に1レベル上昇（上限5）。同色連結塊は1地層。Lucky全列掘削も各列の現在Lv.を使い、終了後に上昇。

盤面外の全LvUPは2番号。HITした枠だけを、既出番号・列番号・ほかのLuckyと重複しない番号へ更新。その他の番号はLv.5未満の列からランダムに1台を強化。全台MAXなら変化なし。

亀裂演出を廃止し、軟化・溶解へ。ドリルは連鎖・回収・せり上がり中も位置を保ち、次の地層へ連続移動。即時連鎖・露出回収・滑らかなスクロールは維持。

素材: assets/canyon-geology/mine-v4.webp, cart-v4.webp, logo-v4.webp。実行時は同一WebPを埋め込み。生成プロンプト: canyon-mine-v4-art-prompts.json。
