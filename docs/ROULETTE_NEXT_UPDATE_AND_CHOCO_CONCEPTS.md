## ユーザー指定の変更

### BET・回転
- BETタイムを15秒から20秒へ変更。
- BET中と抽選終了後も抽選機の回転を続ける。ただし別タブ/メニュー表示等の内部休止は維持する。
- 待機回転から抽選へ移る際に、回転角度や見た目を初期位置へ瞬間移動させない。
- 通常ゲームの抽選が終了しても、盤面のキュー・連鎖・補充が終わるまではリザルトに移らない。

### 発射タイミング
通常速度での仕様。盤面の演出処理時間には依存させない。

| 球 | 発射時点 |
|---|---|
| 1 | BET終了または「すぐ開始」 |
| 2 | 1球目の発射から2秒後 |
| 3 | 2球目の発射から2秒後 |
| 4 | 最初の3球の入賞が揃った時点から5秒後 |
| 5 | 4球目の発射から2秒後 |
| 6 | 4・5球目の入賞が揃った時点から5秒後 |
| 7 | 6球目の入賞から5秒後 |
| 8 | 7球目の入賞から5秒後 |

- 通常抽選の「すべての盤面の処理完了待ち」を外す。
- 入賞順序が発射順と逆転しても、前のグループに未入賞球があるのに次のグループへ進めない。
- 到着した番号は既存の原子的バッチ処理へ渡す。1〜3球は同時消去1回、4〜5球も同時消去1回。6〜8球は各1回。
- 前グループの連鎖中に次グループの番号が到着した場合は、Engineのキューに保留して順序を守る。表示演出だけを先に消すことはしない。
- リセット・モード変更では未発射の予約や着弾待ち状態をすべて取り消す。
- 70球JPCの発射制御は今回の通常8球変更から分離する。

## 音声の追加不具合

報告: 2ゲーム目以降に音声が流れない場合がある。強制終了・即リセット後に起こることがある。
根本原因はまだ断定していない。

### 確認対象
- BGMの曲選択・load/play・フェード・停止、AudioContext再開、効果音読み込みの非同期競合。
- 古いラウンドのPromiseやフェード終了処理が、新しいラウンドのBGMをpauseしたり音量を0にしないか。
- 強制終了後にBGMのgain、音声準備フラグ、効果音の接続先、予約済み音源が正常に戻るか。
- ユーザーの音声ON/OFF設定を勝手に変更しないこと。音声確認モーダルは復活させない。

### 修正・テスト方針
- 音声処理全体の世代番号を統一し、ラウンド・リセット・モード切替をまたいだ古い完了処理を無効にする。
- BGMの予約フェードと停止コールバックを解除してから音量を通常値に戻す。
- 通常開始、通常終了→次ゲーム、発射中リセット、連鎖中リセット、リザルトのフェード中リセット、連打リセット、JPC往復、背景タブ往復をそれぞれ検証する。
- 読み込み遅延やplay()の拒否も再現し、許可後の通常タップで復帰できることを確認する。
- 再生状態・音量・時間の進行だけの自動検証と、iPhone実機で実際に聞く確認を区別する。

## 第2ゲーム: チョコ掘削ゲームの素材案

ここからは未実装のオリジナル案。既存作品のルールをそのまま再現すると決めたものではない。
基本は「厚みのあるチョコブロックを掘り進め、深部の大きなケーキやお宝層に到達する」方向。
通常地形はチョコ、節目の大物はチョコレートケーキにすると、第1ゲームの平たいクッキーと見た目を区別しやすい。

| 素材案 | 形・見分け方 | 壊れ方・ゲーム上の役割案 |
|---|---|---|
| ミルクチョコタイル | 明るい茶色、厚い角丸正方形、四分割の溝と丸いハイライト | 基本地形。大きな角片と細かい粉に割れる |
| ビターブロック | 濃茶、厚い面取り、中央にカカオの刻印 | 硬い地形。表面に大きなひびが段階的に広がる |
| ホワイトショコラ | 乳白色、柔らかい波紋と絞り模様 | 柔らかい層。薄い削り片がほどけるように消える |
| いちごショコラ | ピンク、いちご粒、隅に小さなハート模様 | 目印になる色付き地層。割れると薄赤の断面が見える |
| 抹茶マーブル | 深緑、白い大きなマーブル模様 | 地層の変化を作る。表面の緑と中の白が分かれて割れる |
| エアインチョコ | 少しふくらんだ形、断面に大きめの気泡 | 脆い地形。小粒がはじけ、一気に進めた感覚を出す |
| ウエハースチョコ | 側面に三〜五本のクリーム層、上面に薄いチョコ | 横に続く地層向け。一層ずつ剥がれる演出にできる |
| ナッツロック | 不規則な角、目立つアーモンド片 | 深部の硬い岩。ナッツとチョコの破片が別々に飛ぶ |
| キャラメルコア | チョコ殻の中央に琥珀色の窓 | 殻を割ると中身が伸びる。ボーナスや回復アイテムの容器候補 |
| ガナッシュケーキ | 濃いスポンジと薄いクリームの積層、艶のある上面 | 中型の多層障害物。削るごとに断面と残り層数が見える |
| フォンダンショコラ | 厚いケーキ外殻、亀裂からオレンジ寄りのチョコ光 | 深部の特殊ブロック。破壊でソースが流れ隣接部を崩す案 |
| ゴールドプラリネ | 金箔、幾何学的な面取り、中央の宝石模様 | 掘り当てるお宝。割れると中から金のキャンディやシュガー |

### 最初の制作セット
- 通常4種: ミルク、ビター、ホワイト、いちご。
- 地層/耐久差2種: ウエハース、ナッツロック。
- 特殊2種: フォンダン、ゴールドプラリネ。
- 節目の大物1種: 2×2マスのガナッシュケーキ。
- 抹茶、エアイン、キャラメルは追加の地層やイベントで増やせる。

### ケーキをより主役にする場合
- オペラケーキ: 黒・茶・薄金の細かな層。階層を削る達成感。
- チョコショート: チョコスポンジと白クリームの厚い二層。上に小さないちご。
- ブラウニー岩盤: 低く密な生地にナッツを埋めた重い地形。
- ロールケーキ地層: 横断面の大きな渦巻き。横穴や通路の目印。
- 宝箱ケーキ: ふた状の板チョコと金箔の留め具。最後に開いて報酬を見せる。

### 美術上の統一ルール
- 正面はマスに収まり、上面と右側面だけに浅い厚みを付ける。等角投影にしすぎて数字を読みにくくしない。
- 色だけでなく、溝・粒・層・渦巻き・刻印で区別する。
- 中央は番号や耐久表示のために空け、トッピングは角や上辺に寄せる。
- 通常、軽いひび、大きなひび、破壊の差分を共通仕様で用意する。耐久状態が少ない素材は不要な中間状態を省く。
- 板チョコは鋭い破片、ケーキは柔らかい粒、ウエハースは薄片、キャラメルは伸びる質感で差を付ける。
- 虹色を第1ゲームと共通のダイレクトJPC用にする場合、通常地形の装飾に乱用しない。

### 継続式の進行案
- 8球終了後も掘った地形、深度、削った耐久を次のゲームに引き継ぐ。
- 配当の主軸は最大LINKではなく、掘り進んだ深度と発掘物に置く。
- 浅部はミルク層、中層はウエハース/クリーム層、深部はビター/ナッツ岩盤、さらに奥にフォンダンや黄金のお菓子遺跡。
- 同じ層を削り切ると画面が下へ送り込まれ、新しい色・断面・背景が現れる。
- 途中BET変更で過去の低BET分まで高額化しないよう、進行に対する報酬価値は積み上げる方式かBET別の進行保存を検討する。
- 出現率、耐久数、配当、継続終了条件は未決定。ここで固定値を実装したとはみなさない。
