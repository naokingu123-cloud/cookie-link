# チョコレートキャニオン：ケーキ連鎖版（2026-10-28）

- 7列×12段。ホワイト、いちご、ミルク、ビターの4種類。上下左右の同色は一体のケーキ。
- 近隣色を選ぶ確率を35%から52%へ変更（選べる近隣がない場合は4色から選択）。
- 番号HITで、その番号を含むケーキを消去。抽選は3・2・1・1・1球の5回。
- ケーキは塊のまま落下し、同色に触れると合体。**全ケーキが落下しきってから**同色4個以上を消去。消去後は再落下・再判定する。3個以下は自動消去しない。
- 配当チョコは落下後に上から露出すれば獲得。銀0.2倍・金1.2倍。通常のケーキ消去自体に配当はない。
- 処理終了後、上端の空行の分だけ盤面が900msでせり上がり、下側にランダムな新しい層が現れる。1行=1m。10mごとに横の看板で表示。
- 補充直後には自動消去しない。次の抽選の解決で落下と4個判定を行う。
- 補充番号は未抽選かつ盤面から失われた番号から45%の確率で候補を選び、新しいマスに配置。番号の重複・抽選済み番号の再登場は禁止。すべての番号が必ず戻る方式ではない。
- 初期盤面には1〜25を1個ずつ配置。配当ありなら深さ・地形を次ゲームへ継続し、配当なしなら次ゲームは0mから。

## 検証

実装の生成・消去・落下・補充を用い、継続地形も含めた40,000ゲームを集計。1〜25の重複なし8球、3/2/1/1/1で処理。JPCとBET別の端数処理は除外。

- 平均配当率：89.2425%
- 500ゲーム単位のバッチ平均80個による参考95%区間：88.26〜90.23%
- 最終検証seed：281028321、281028322（各20,000ゲーム）。
- 初期配当1.1倍/10倍をそのまま使用すると新ルールでは過大になったため、配当を0.1倍刻みで調整。
- 回帰テスト：4個消去は全落下後、3個は残存、複数HITの二重消去なし、番号の一部補充と既抽選番号除外、同色の落下途中合体、露出だけで配当、80ゲームの全8球処理、深さ継続、0BET、保存・中断復元。

## 画像素材

内蔵画像生成ツールで4画像を個別に生成。`assets/choco-dig.js` の `chocoCakeSources` に192×192 WebPとして保存し、`index.html`にも同じデータを埋め込む。画像が未ロードの瞬間だけ色付きの角丸四角を代替表示。

使用プロンプトの共通指定：正方形、角は少し丸い、ほぼ正面の正投影、薄いケーキ層、艶のある日本のメダルゲーム風の立体表現、中心は番号用に空ける、透明背景、文字・皿・はみ出す飾りなし。

- ホワイト：乳白色のホワイトチョコの艶、隅に控えめな浮き彫りの渦模様。
- いちご：同じ形と構図、鮮明なピンクのいちごアイシング、隅にいちごの浮き彫り。
- ミルク：同じ形と構図、明るいキャラメル色のミルクチョコ、隅に板チョコの浮き彫り。
- ビター：ミルクを参照して同じ形と構図を保持、濃いエスプレッソ色のビターチョコ、隅にカカオ豆の浮き彫り。
