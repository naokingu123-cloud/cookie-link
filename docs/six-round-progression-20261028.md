# シックスドロップ・ラウンド突破率（2026年10月28日）

現行エンジンを使用した 50,000 ゲームのモンテカルロ集計。実プレイ履歴の集計ではありません。

抽選は1〜25の一様・重複なし8球、処理単位は3球・2球・1球・1球・1球。盤面生成、3色チャンス盤面、シュガー配置による乱数消費、上からの補充を含みます。0.2秒刻みの補充は表示上の演出であり、盤面や判定を変えません。

「到達後の突破率」は、そのラウンドへ到達したゲームを分母とします。残り球数は実際の進行に従い、各ラウンドで8球を新しく引く設定ではありません。8球目で役が成立すれば突破に数えますが、次ラウンドの盤面は生成しないため、次ラウンド到達には数えません。R5突破は最終ラウンドクリアです。役以外の4個以上消去だけでは突破に数えません。

同一試行の配当率：89.382%（JPC・メダル端数処理を除く）。95%区間は各突破率にWilson法を使用。後半は到達数が少なく誤差が大きくなります。
