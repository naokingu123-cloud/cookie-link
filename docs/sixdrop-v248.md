## 同色4個以上の消去

六方向の隣接関係でつながった同色ドロップが4個以上になると、そのかたまりを消去する。直線に限らず、折れ曲がった形や枝分かれした形も対象。3個以下では消去しない。

直線・トライアングル・ヘキサゴンが成立した場合は、従来どおり、その役の色を盤面全体から消去する。離れた場所の同色ドロップも対象になる。役を含まない通常の4個以上のかたまりは、そのつながりだけを消去する。

1球のHIT → 番号の消去 → 支持と転がりを含む落下 → 役と同色のつながりを判定 → 消去 → 再落下、を盤面が落ち着くまで繰り返す。役を伴わない消去も全消しプログレッシブへ加算するが、独立した役配当は設けない。

初期配置と補充配置では、新たなドロップと既存ドロップのつながりを含めて検査し、補充完了時に同色4個以上のかたまりや成立済みの役を残さない。残存ドロップの色・番号は変更しない。上から到達できない内部の穴へ直接ドロップを置かない。

既存の3個のかたまりに囲まれ、4色のどれを置いても消去が成立してしまう位置は空けておく。その穴のために支えを失う新規ドロップも除外し、落下後に安定する配置だけを注入する。可能な限り元の高さを維持し、既存ドロップの色変更や補充直後の自動消去で回避しない。

落下処理はv247と同じ支持・転がり・垂直空間の落下を使用する。連鎖回数の安全上限は盤面の最大75個と最小4個の消去から18回とし、通常のかたまり消去で8回を超える連鎖を途中終了させない。

## ゲーム中に変わらない4色構成

ゲーム開始時の累計消去数で、そのゲーム全体の4色を確定する。100個の境界をゲーム途中で超えた場合も、初期配置・すべての補充は確定済みの4色を使用する。追加色は次ゲームから登場する。

| ゲーム開始時の累計消去数 | そのゲームで出現する4色 |
| --- | --- |
| 0〜99個 | 青・水色・緑・黄緑 |
| 100〜199個 | 水色・緑・黄緑・黄色 |
| 200〜299個 | 緑・黄緑・黄色・オレンジ |
| 300〜399個 | 黄緑・黄色・オレンジ・赤 |
| 400〜499個 | 黄色・オレンジ・赤・ピンク |
| 500個以上 | オレンジ・赤・ピンク・紫 |

500個以上では紫・ピンク・赤・オレンジの4色を維持し、最初の色へ循環しない。全消しプログレッシブと同様に、シックスドロップ自身のゲーム終了WINが0の場合に累計消去数をリセットする。

## 全消しプログレッシブと配当

- 消したドロップ1個につき、そのゲームのBETの0.05倍を加算する。番号HIT、通常のかたまり、役成立時の同色全消去をすべて数える。
- 例：100 BETなら1個につき5 WIN、3000 BETなら1個につき150 WINを蓄積する。
- 内部残高はメダルの100分の1単位で保持し、端数を途中で捨てない。全消し時のメダル配当は整数に切り捨てる。
- 消去した順に各ドロップの加算履歴を生成し、消去演出に合わせて表示額を連続的にカウントアップする。計算済みの後続連鎖分を先に表示しない。
- 全消し時は、その時点のプログレッシブ全額を通常の役配当に追加する。獲得しても残高を減らさず、次の消去・次ゲームへ継続する。
- シックスドロップ自身のゲーム終了WINが0の場合のみ、残高と色の進行を0へ戻す。他ゲームだけの配当はこの判定に影響しない。シックスドロップに参加していないゲームではリセットしない。
- 既存v247残高はそのまま引き継ぐ。過去の消去分を0.05倍へ遡及再計算しない。BET変更も過去の残高へ影響させない。
- 強制キャンセルではゲーム開始前の残高と消去数を復元し、精算の再送で二重加算しない。

通常の役配当はv247と同じ。同じゲーム内でその役が成立した回数をnとすると、n回目の配当は直線がBET×0.10×n、トライアングルがBET×0.30×n、ヘキサゴンがBET×0.60×n。P/O設定によってこの配当表や0.05倍の加算率を変更しない。

## 表示

生成済みのキャンディ瓶を維持し、上部をキャンディの包装紙を模した枠の「全消し nWIN」へ変更。数字は他ゲームと共通の`fitGoldenNumber`、`.gold-number`、`ArcadePayout`を使い、右寄せする。右上の色・進行の説明と右下の説明文を取り除き、役別の配当欄を残す。

主画面とミニ盤面で同じ絶対色を使用する。青と水色、赤とピンクを区別する。紫の既存色IDを変更せず、新しいピンクのIDを追加する。

非表示タブや別ゲームの表示中も精算処理を進め、表示用の残高を同期する。画面復帰のために蓄積額や消去を再実行しない。

## サーバー画面の番号別グラフ・文字色

各候補番号について、参加中の各ゲームで新たに増える実際のWINを計算し、そのゲーム自身のBETを分母として色を決定する。複数のゲームが該当する場合は、最高役・10倍・3倍の順に優先する。

| 色 | その番号で新たに獲得するもの |
| --- | --- |
| 赤 | いずれかのゲームで、そのゲームのBETの3倍以上の増加WIN |
| 紫 | いずれかのゲームで、そのゲームのBETの10倍以上の増加WIN |
| 虹 | いずれかのゲームで、新たに成立する本来の最高役 |

最高役は既存の各ゲームの判定を使用する。全消し・全埋め・全反転などの新規成立と、キャニオンの新たな500m以降の100m区切りボーナスを対象とする。通常配当が50倍でも最高役が成立しなければ紫となる。既に獲得済みの合計WINや最高役だけでは次の番号を着色しない。

棒の高さ・表示WIN・倍率の数値は全ゲーム合計を維持する。色は各ゲームの判定を使用し、一部ゲームが計算中でも確認済みゲームで条件を満たせば表示する。全プレイヤー合計行も、各プレイヤーで確認された色の最大段階を採用する。

クライアントは既存の予測キャッシュから`numberColorTiers`と`colorBasis: per-game-new-award-v248`を送信する。サーバーは認証済みプレイヤー・同一ラウンド・同一抽選球数の情報だけを管理者用予測に保存し、`colorTiers`として返す。旧クライアントの予測には合計金額から推測した色を付けない。抽選更新・精算・切断・期限切れで金額と色を同時に失効する。
