# SWEETS LINK v287 — ダンゴデビンゴ確率対応配当

新規ゲームのルール改定版は **287**。v285 / v286以前に開始・保存したゲームは、独立した旧285エンジンで配当とFREE配置を最後まで固定し、精算途中のルールを切り替えない。水色「+FREE」団子と緑の初期FREEのHIT演出は維持。

## 改訂配当表（BET倍率、ODDS適用前）

| ライン長 | 1個成立 | 2個成立 | 3個成立 |
| --- | ---: | ---: | ---: |
| 2個 | —（0倍） | 0.2倍 | 2.2倍 |
| 3個 | 0.1倍 | 1.2倍 | 30倍 |
| 4個 | 0.3倍 | 4倍 | 100倍 |
| 5個 | 0.5倍 | 75倍 | 5,000倍 |
| 6個 | 1.2倍 | 250倍 | 10,000倍 |
| 7個 | 0.6倍 | 400倍 | —（成立不可能） |

極端な希少役も**配当表の最高基礎倍率10,000倍**に収める。7個ライン×3個は最低18マスが必要で、最大印15マスの現行仕様では成立不可。異なる長さの配当は加算され、ODDS UPが最後に掛かる。このため**合計獲得倍率（複数役とODDSを含む）は10,000倍を超える場合がある**。本改定は各役の表倍率の上限であり、最終WINの一律打ち切りではない。

確率と配当の相対関係を重視し、頻出の2個ライン×3個は従来5倍から2.2倍へ減額、5個ライン×2個は1.5倍から75倍、6個ライン×2個は30倍から250倍、7個ライン×2個は50倍から400倍へ増額。5個ライン×3個は50倍から5,000倍、6個ライン×3個は250倍から10,000倍に設定する。7個ライン×1個が6個ライン×1個より低倍率なのは、3種類の初期配置とAUTOの下では両者の出現率が長さの順と一致しないため。

## 自動配置・成立頻度・P/Oの再計算

抽選8球、初期緑FREE3個、25番号から独立に選ぶ水色+FREE3個、前半5球の水色HITによる配置FREE 1～4個、通常のODDS条件は変更しない。配当変更により「おまかせ」が別の場所を選ぶ可能性があるため、旧配当で測った確率を流用せず、**新配当でのFREE自動配置を全探索し直した**。

3種類の盤面について、前半5球全53,130集合×FREE予算1～4個、後半3球全1,140集合（解析的包除）に、水色FREE3個の重み1,140:950:200:10を掛けて厳密積分した。

| 初期緑FREE配置 | 新AUTO理論配当率 |
| --- | ---: |
| 縁の三粒 [0,21,27] | 46.4525599206% |
| 角寄りの三粒 [1,20,22] | 157.4844696578% |
| 段違いの三粒 [3,4,10] | 206.6896650624% |

段違いの三粒を従来どおり1.5%に固定すると、他の2配置の混合で**48.8561164977～158.2225475889%**が実現可能。目標50～150%のどの値も、その初期配置の混合重みだけで正確に合わせられる。目標設定を理由として抽選番号や水色3マスを差し替えない。

計算根拠は `docs/dango-v287-calibration.json`（全101設定、84個の整数ベクトル）、`docs/dango-v287-exact-frequencies.json`（ライン成立確率）および `scripts/dango-v287-enumerate.cpp`（再現用C++）に保持する。旧v285の表と実行中セーブデータは変更しない。

**計算対象の限界:** BETに対する直接配当の期待値、BETが10の倍数なら整数精算の丸め差なし。FREEを手動で配置したとき、少額BETの切捨て差、実機の球バイアス、共通Sugar/JPCは含まない。個々のゲームの収支は設定値に一致するとは限らない。
