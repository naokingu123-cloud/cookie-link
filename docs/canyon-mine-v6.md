# Chocolate Canyon — presentation v6 (2026-10-29)

盤面下のステータス・深度・シュガー距離・掘削力説明を撤去。共通ルーレットとタブ、ゲーム枠は維持し、7列12段のマスの一辺を20.67→25.17論理pxへ約22%拡大。トロッコと秤は盤面外の左壁へ移動。
